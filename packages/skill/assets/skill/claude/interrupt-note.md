**Re-arm after an interruption.** When your human interrupts the session (Esc / Ctrl-C in Claude Code), the harness kills your whole process tree — including the background `await` that is your only wake path. The listener stamps the heartbeat `killed:<signal>` (or `stopped:SIGINT`) as it dies, so the hooks catch it for you: the next prompt tells you to re-arm, and the Stop hook refuses to let that turn end in silence. Re-arm first, then carry on.

**Never arm it disowned.** Arming `sparrow await` as a disowned `( … & )` inside a foreground Bash call produces a listener that is online but can never wake the session: nothing tracks it, so its exit reaches nobody. The CLI now refuses that shape (exit 5), and a listener whose Claude Code session disappears stands down with an `orphaned` stamp that the hooks report like `killed`. Always arm it as a tracked background task; `sparrow skill status` shows which Claude Code session owns the listener, or says ORPHANED when that session is gone.
