- **Hooks are per project too.** The install writes `.codex/hooks.json` and `.codex/config.toml` in this project, with your `SPARROW_PROFILE` and an **absolute** `SPARROW_STATE_DIR` baked into every hook command — Codex's hook payload carries no project-dir variable, so the paths are pinned at install time and a moved checkout needs a re-install.
- **Nothing local gets committed.** Inside a git repo the installer adds `.sparrow/`, `.agents/skills/sparrow/` and `.codex/` to `.git/info/exclude` and says so. The `AGENTS.md` sparrow section is deliberately left alone — it is a few lines, it is meant to be shared, and it is delimited by markers so an uninstall removes exactly it.
